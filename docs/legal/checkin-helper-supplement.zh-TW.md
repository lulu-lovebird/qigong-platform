## 服務目的與使用資格

小幫手以練功打卡、心得交流、成就榜及榮譽勳章，陪伴白雁學員養成持續練功的習慣。這是學員共同練功與交流的服務，不是私人日記，也不提供醫療診斷或治療。

首次及重大版本更新時，須先閱讀並明確同意本補充說明，才能使用一般學員功能。同意不等於學員資格核准；仍須由白雁工作人員核對使用資格。不同意或資格失效者仍可閱讀政策及聯絡隱私窗口，不因此喪失既有資料權利。

## 資料與預設分享

必要資料可能包含平台識別、報名及地區、練習日期、時區、功法、同意版本，以及安全和稽核紀錄。報名及聯絡資料不列入學員分享內容。

同意後新建立的打卡紀錄，其日期、功法、心得及感受標籤預設分享給小幫手內具有效資格的白雁學員與有效授權工作人員，跨所有地區交流；不是一般網路公開。打卡衍生的累計／連續天數、排名與勳章，依各功能明示的範圍呈現。

分享使用暱稱或遮罩識別，不自動公開真實姓名、Email、電話或平台身份識別碼。文字及練習資訊仍可能使熟人辨識分享者，不能保證完全匿名。不得未經本人同意公開他人個資或冒用他人身份。

心得與感受不是必填。請避免填寫病歷、診斷、聯絡方式及其他不必要的敏感資訊；若自願填寫涉及健康的心得或感受，須另行明確同意此類資料依本服務目的及分享範圍處理，不能只因接受一般政策就推定同意敏感資料處理。

新紀錄的更正會更新其學員可見的分享內容；打卡頁應持續提示分享範圍。撤回分享後，不因後續更正而自動重新公開，重新分享須另行確認。

接受新版不會自動公開先前的私密紀錄，更正舊私密紀錄也不會自動公開。舊資料如要分享，需另外預覽並明確確認。

本次同意不涵蓋一般網路公開、廣告、販售個資、LLM／AI訓練或任意合作系統讀取。外部系統讀取保留獨立同意與授權；不自動發行外部憑證。WhatsApp 主動通知同意及 STOP 退出通知亦與本補充說明分開處理。

## 停課、退學及移除資格

停課、退學或不再具資格者，由具有相應地區管理權限的人員停用小幫手使用資格。停用不是直接刪除帳號或所有歷史資料，不擅自影響其他獨立平台報名紀錄或管理員授權。

停用後不能再讀取其他學員內容、打卡或新增分享；既有連結與 API 同樣受限制。其歷史分享不再提供其他學員閱讀；已被閱讀、截圖或複製的內容無法收回。

管理人員仍可依既有授權範圍、必要管理目的及資料保存規則查看歷史。共享內容的管理端查閱不等於將舊私密內容變成全區公開；原有私密心得權限仍依角色與地區限制。
